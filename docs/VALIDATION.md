# 验证记录

日期：2026-10-25。

## 功能实测

2.0.0 核心功能在小米 2304FPN6DC、原厂 HyperOS、Android 16 / API 36、无 Root 的设备上完成：

- 系统配对窗口保持打开，通过应用通知输入配对码成功。
- 外部 Shizuku 服务停止，原专用后台结束后，应用通过已保存身份独立无线启动新后台，后台实际 UID 为 2000。
- 加密保存的 ADB 身份可重新载入，公钥一致。
- 卡 1 切 JP、卡 2 切 US、双卡切 JP，分别读回实际系统国家码；单卡操作不改变另一卡。
- 每次停止均恢复两张卡原国家码；最终临时和持久覆盖均为空。
- 注入配置偏离后，持续检查自动修复目标国家码。
- 模拟后台断开时保留恢复快照，重连后通过通知停止恢复。
- 地区列表包含 10 个选项，选择和保存有效。
- 在本次 HyperOS 设备上，关闭无线调试后已启动后台仍可继续工作。
