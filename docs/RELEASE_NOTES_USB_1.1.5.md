# 潮汐改卡 USB 工具 1.1.5

修复 1.1.4 的诊断信息缺失：当 ADB 启动异常或非零退出时，旧版只显示“ADB 未正常返回设备列表”，无法继续区分电脑运行环境与手机连接问题。

- 先运行 ADB 客户端自检，再查询设备；自检失败时不继续查询设备 / 服务，避免把尚未完成查询误认为没有手机。
- 记录 Win32 启动错误码、进程退出码及已识别的服务连接 / 协议错误类别；未知错误保留类型和数值，不臆测原因。
- 显示 Windows 版本、系统 / 工具进程位数、ADB 架构，以及 `adb.exe` / 两个随附 DLL 是否存在。
- Windows 未提供 `Present` 字段时保留 USB 候选接口并注明不确定性；明确断开的接口仍排除。
- 保留脱敏复制、华为官方驱动入口、高 DPI 布局及原签名 Android **2.4.1** APK。

## 使用

完整解压 **TideCard-USB-1.1.5-Windows.zip**，运行其中 EXE；不要只复制 EXE，需保留旁边的 `adb` 子文件夹。点“连接诊断 / 华为”，反馈完整新版脱敏报告。

USB 模式继续使用“传输文件”或“传输照片”，不要求 MIDI。界面和 Edge 能打开，不等于独立的 ADB 客户端及本机服务已正常运行。驱动排查应在客户端自检正常后进行，步骤与来源见 [华为连接诊断](https://github.com/DustinYe/TideCard-Android/blob/usb-v1.1.5/docs/HUAWEI_USB.md)。

1.1.5 同时附在 [Android 2.4.1 发布页](https://github.com/DustinYe/TideCard-Android/releases/tag/v2.4.1)。它是电脑端诊断修复，**受影响华为电脑 / 手机不在现场，连接根因仍需新版报告验证**，不代表已经解决该机连接或改卡问题。

Windows EXE 暂无 Authenticode 签名。工具包、源码包及 SHA-256 校验随附发布；Android 应用内更新仍以 2.4.1 为最新版本。

主机验证通过 154 项诊断断言、43 项模拟激活断言与 28 组布局检查（1390 项尺寸 / 可达性断言）。真实随附 ADB 自检和本机服务查询正常，当前没有连接手机。
