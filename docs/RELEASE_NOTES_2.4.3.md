# 潮汐改卡 2.4.3

新增“清除旧地区配置”，便于处理其他改卡工具或旧版本遗留造成的启动失败、异常国家码和持久覆盖。

- 主界面或“设置 → 旧地区配置”进入，选择卡槽，先检查恢复目标，再确认一键清除；空卡槽自动跳过。
- 支持地区 / 运营商名称的部分字段及异常值。仅确有持久残留时尝试持久清除；系统拒绝或回读未确认时显示未完成。
- 含 APN / IMS 等其他字段、无法核对原配置、换卡或配置变更时停止；潮汐有恢复备份时先走原有停止恢复流程。
- 简体中文、繁體中文和 English、浅色 / 深色模式同步。沿用原签名，版本码 **14**；Windows 配套工具 **1.1.10** 随附新版 APK。

覆盖安装后请**重新激活内置后台**。停止其他改卡工具后再清除，确认显示“国家码已核对”后回主界面开始。具体步骤、清除范围和系统限制见[使用说明](https://github.com/DustinYe/TideCard-Android/blob/v2.4.3/docs/CARRIER_CLEANUP.md)。

已通过主机清除逻辑、Android 11 / 14 模拟界面、无线配对回归、Release / 测试包构建与 lint；签名保持一致。**受影响 OPPO 不在现场，没有真实清除、权限委派或 SIM 写入验证**。先前 OPPO A3x 5G 成功是用户反馈，不能代替本次另一台手机的验证。

现有用户可从“设置 → 检查更新”下载安装。
