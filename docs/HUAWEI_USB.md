# 华为 / HarmonyOS 4.x USB 连接诊断

## 反馈与检索结果

反馈设备名称为 ALN-AL10，用户报告系统为 HarmonyOS 4.2.0.223。截图显示 USB 调试和“仅充电模式下允许 ADB 调试”已开启；资源管理器能打开手机存储，旧版电脑工具 1.1.2 未列出 ADB 手机。这只能证明文件传输可用，不能证明 ADB 接口、驱动与 RSA 授权均已就绪。尚未取得该电脑的设备管理器或 ADB 原始输出，不能确定根因。

检索日期：2026-10-29。

- [Shizuku 原始反馈 #846](https://github.com/RikkaApps/Shizuku/discussions/846)：2024-12-04 有人报告鸿蒙 4.2 的 `adb devices` 只有列表标题。检索时为 0 条回复，没有已验证的解决办法；相似反馈不能作为系统缺陷或通用修复的依据。
- [华为官方连接排查](https://consumer.huawei.com/cn/support/content/zh-cn00698619/)：HarmonyOS 4.3 及以下可通过 USB 调试或 HDB 连接手机助手，电脑端选择“**HarmonyOS 4 及以下**”。检查设备管理器中的 adb / hdb 驱动，并通过手机助手安装官方 USB 驱动。手机助手的 HDB 连接并不表示潮汐改卡需要的 ADB 已就绪。该页面对 HarmonyOS 5 的 HDC 流程另有说明，不应直接套用到本次 4.2 反馈。
- [华为 USB 调试说明](https://consumer.huawei.com/cn/support/content/zh-cn00407281/)：在机主 / 主空间操作，选择“传输照片”或“传输文件”；HarmonyOS 4.x 及以下可开启“仅充电模式下允许 ADB 调试”。本次截图已开启后一个开关。
- [Android 官方 ADB 文档](https://developer.android.com/tools/adb#usb-backends)：Windows 默认使用原生 USB 后端，Windows libusb 后端仍标为实验性。后端设置由 ADB 服务读取，客户端环境设置不能改变已经运行的服务。

## 1.1.4 工具调整

新增“**连接诊断 / 华为**”，只读检查 ADB 列表和 Windows 当前华为 USB 节点，区分：已授权、待 RSA 授权、离线、ADB 接口驱动异常、接口存在但列表为空、仅有文件传输 / HDB / HDC，以及接口查询失败。提供官网驱动入口、设备管理器和复制脱敏诊断。多台手机的 PnP 节点不强行对应到某一部手机。

仅在自己的 ADB 子进程隔离远端服务器、端口、设备选择、跟踪和 USB 后端等环境覆盖，固定本机 5037 端口，为新启动的服务设置 Windows 原生后端。全局环境和已有服务不变；能读取 `server-status` 时显示当前后端，LIBUSB 会提示实验性及生效条件。不强制结束服务，不切换网络 ADB，不自动安装驱动。

复制报告不含手机序列号、PnP 实例尾部、ADB 密钥或激活令牌，不自动保存或上传。官网按钮由用户点击后通过浏览器打开。

**这是诊断与客户端兼容修复，不能代替受影响电脑上实际缺失的驱动或手机授权。**

## 1.1.5：先检查 ADB 客户端能否运行

后续收到 1.1.4 报告：`ADB 列表有效=False`、后端未获取、华为节点数为 0。旧版将启动异常和非零退出统一为“ADB 未正常返回设备列表”，没有保留错误类别。该报告不足以区分缺文件、Windows 加载失败、本机 ADB 服务异常或手机连接问题，节点数为 0 也不能单独作为没有插手机的证据。

1.1.5 先调用无需连接手机的 `adb version`，记录客户端自检，再查询设备列表。客户端自检失败时不继续查询设备 / 服务；设备查询失败时不再重复查询服务状态。报告保留 Win32 启动错误码、十进制 / 十六进制进程退出码及已识别的服务连接 / 协议错误类别，同时继续排除原始异常正文、任意 ADB 输出、路径、序列号和令牌。另记录 Windows 版本、系统 / 工具进程位数、ADB PE 架构及 EXE / 两个 DLL 是否存在。

Windows USB 查询不再用 `Present=TRUE` 丢弃字段缺失的候选节点，明确排除 Present=False 或错误码 45 的已断开节点。Present 未提供时保留候选项并注明无法确认其当前在线状态。

应用界面及 Edge 能运行，不能证明单独的 ADB 程序、依赖模块与本机服务能运行。新版只收集与诊断相关的本机状态，不自动安装驱动、调整防护设置或结束已有 ADB 服务。

USB 模式保持“传输文件”或“传输照片”，不要求使用 MIDI。该建议以本页所引华为官方 USB 调试说明为依据；在 ADB 客户端失败时切换 MIDI 不能解决文件缺失或 Windows 加载错误。

## 交给用户的操作步骤

1. 完整解压 `TideCard-USB-1.1.5-Windows.zip`，运行其中 EXE。确认 EXE 旁有 `adb` 子文件夹及其中 `adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll`。随附 APK 仍为 2.4.1；已装更高版本时不要降级。
2. 手机解锁并保持 USB 调试开启，切换为“传输文件”或“传输照片”，重新连接。
3. 点“连接诊断 / 华为”。先看客户端自检和设备查询是否通过；未通过时保留完整新版脱敏报告。客户端正常且提示 ADB 接口未枚举或驱动异常时，再从“华为官方驱动入口”获取官方手机助手，选择“**HarmonyOS 4 及以下**”，通过菜单 → 设置 → 常规设置 → 其他方式 → **安装 USB 驱动**，完成后重新插线。
4. 手机出现“允许 USB 调试”的 RSA 弹窗时，确认是自己的电脑后允许。HDB 授权不能代替这一步。
5. 回工具刷新，明确选择目标手机，再安装 / 更新并激活。后台就绪后，仍需单独验证这台 ROM 的改卡与恢复能力。
6. 仍无设备时，复制脱敏诊断，并记录设备管理器中 ADB 接口是否出现及错误码，以区分驱动、未暴露接口和授权问题。
