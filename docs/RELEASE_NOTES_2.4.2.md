# 潮汐改卡 2.4.2

修复系统已显示无线调试配对码、应用通知仍一直等待且没有输入入口的问题。

- 自动发现失败时，通知始终提供“手动配对”：直接输入配对弹窗底部端口与六位码，中间加空格，无需切回应用或分屏。
- 配对后未发现连接端口时，可在普通通知内输入无线调试主页面的连接端口，继续启动内置后台。
- 增加“重新搜索”、超时引导、解析超时与有限重试；隔离迟到回调。Android 13 及以上优先使用 Wi-Fi 发现，Android 14 及以上检查多个服务地址。
- 保留实况通知可选设置：输入时转为普通通知，成功反馈后结束实况展示。通知刷新保持当前输入令牌，旧会话操作与重复提交受限。
- 新提示包含简体中文、繁體中文和 English。Android 版本码为 **13**，沿用原签名与数据；Windows 配套工具 **1.1.9** 随附此 APK。

**使用**：保持系统配对弹窗打开，展开潮汐通知点“手动配对”，输入 `端口 六位码`（例如 `39461 123456`，必须换成当前系统值）。若配对后仍等待启动，回到系统无线调试主页面，在通知的“输入连接端口”中填写主页面端口。详见[配对说明](https://github.com/DustinYe/TideCard-Android/blob/v2.4.2/docs/WIRELESS_PAIRING.md)。

已有改卡会话先停止并恢复，再覆盖安装；升级后重新激活内置后台。无法恢复时保留数据，不要通过卸载或清除数据尝试修复。

**验证范围**：输入、NSD 队列及 Android 11 / 14 的主机通知 / 服务回归通过；Release、仪器测试包、lint 与签名检查通过。OPPO A3x 5G 不在现场，尚未验证该 ROM 的真实配对、通知显示和后台启动。Windows 端 ADB 的 socketpair 故障是另一条路线的问题，本版没有重置其网络配置。

附件包含签名 APK、对应源码、配套 Windows 工具、SHA-256 与 APK 签名摘要。现有 Android 用户可在应用“设置 → 检查更新”获取此版。
