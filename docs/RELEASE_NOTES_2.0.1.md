# 2.0.1

公开发布前补全开源许可和来源说明，提供应用内许可阅读入口。

- 内置无线调试配对与专用后台，无需另外安装 Shizuku。
- 支持 10 个目标地区、卡 1 / 卡 2 / 双卡选择、持续保持、停止恢复。
- 增加 Shizuku 改写来源声明，以及原生依赖的完整许可副本。
- 上传内容排除签名私钥、密码和设备激活凭据。

核心改卡及独立无线激活功能已在小米 2304FPN6DC、原厂 HyperOS、Android 16 / API 36 上验证。其他机型和 ROM 未逐一验证；没有进行整机重启测试。

此工具改变系统报告的部分 SIM 地区配置，不修改实体 SIM，不提供 VPN，也不保证第三方应用一定可用。卸载或清除数据前请先停止恢复。
