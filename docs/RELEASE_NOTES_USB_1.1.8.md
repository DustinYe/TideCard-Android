# 潮汐改卡 USB 工具 1.1.8

修复点击“OPPO / 厂商帮助”后，菜单关闭过程可能报 `ObjectDisposedException / ContextMenuStrip` 的问题。

旧代码在菜单 `Closed` 事件内立即释放菜单，但 WinForms 此时尚在完成关闭流程。在本机复现了与用户截图一致的异常。现在每个诊断窗口持有并复用一个菜单，窗口释放时再统一清理；菜单选项和厂商链接保持不变。

- 新增菜单生命周期回归，覆盖重复打开 / 关闭、点击外部 / 键盘 / 选项 / 主动关闭 / 焦点变化、四个选项的准确路由，以及窗口关闭和直接释放。
- 保留 1.1.7 的电脑端检查更新、下载校验、原目录更新与重启。1.1.7 用户可直接点击底部“检查更新”获取此版；更早版本请完整解压 **TideCard-USB-1.1.8-Windows.zip**。
- 随附相同原签名 **Android 2.4.1** APK；本次修复不涉及手机安装、激活或改卡。

Windows EXE 仍没有 Authenticode 代码签名，可能显示 SmartScreen 提示。本版没有加入云端日志上传；现有诊断复制仍在本机，检查更新才主动请求 GitHub。

此菜单异常与 OPPO USB 连接失败是两个问题。朋友的 OPPO 手机和故障电脑不在现场，未确认其连接或改卡效果。
