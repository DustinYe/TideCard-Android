# 地区圆盘与外观

## 地区目录

冻结 249 个 ISO 国家和地区的两位代码，中文、英文显示名从 Android 内置 Locale 数据生成，无网络查询。目录校验对照主机 JDK 的 `Locale.getISOCountries()`；本地化名称可能因 Android 版本有细微差异。

原有 10 个地区的显示名和运营商字符串保持原样，以便接续已知残留和保留旧快照。新增项使用 `TideCard XX` 作为显示标签；它是应用标签，不代表更换了实体 SIM 或签约运营商。恢复检测仍只接受明确列出的国家码 / 名称组合与原有三个临时字段，额外字段、持久覆盖及异常组合继续拒绝。

## 圆盘交互

页面以圆形表盘为视觉参考，由本项目 Canvas 绘制，无第三方表盘图片或商标素材。一次显示至多八个相邻地区码，中心预览完整选项；圆盘旋转、点圆点、前后按钮、方向键和无障碍滚动都只修改草稿。中文、英文、两位码搜索支持名称精确匹配优先和无结果状态。完整名称在圆盘下方可换行显示；圆盘内长名称最多两行省略。

点“使用”后通过 Activity 结果保存，主页面会再次检查当前没有运行 / 待恢复会话。返回不保存；没有匹配结果时不能确认。页面可整体滚动，搜索键盘和较大字体不会把确认区固定裁切。

## 外观

主页“设置 → 外观模式”提供跟随系统、浅色、深色。模式存于应用私有偏好，通过配置 Context 和本机主题资源作用到应用各页面；不更改全局夜间模式。系统模式变化由 Activity 配置生命周期重新呈现；手动模式会在 Activity 恢复时检查偏好并重新创建界面。

浅色为柔和浅绿背景，深色使用深绿黑背景与薄荷色强调；圆盘保留独立的深色表盘。主文字、次级文字及按钮文字的颜色对比度有主机检查。通知本身沿用系统模板，由系统外观控制；未宣称任意 ROM 的启动画面都会与手动强制主题完全一致。

界面重建不会清除地区、卡槽、配对身份或恢复快照，现有服务继续负责配置保持。实机已验证新增荷兰运行期间切换深色后快照与配置均保留，停止后恢复原地区。

参考：[Android 深色主题](https://developer.android.com/develop/ui/views/theming/darktheme)、[圆形设备设计](https://developer.android.com/design/ui/wear/guides/get-started/design-for-wearables)。只参考通用配色、形状和交互原则，不代表与 Google / Pixel Watch 有官方关联。
