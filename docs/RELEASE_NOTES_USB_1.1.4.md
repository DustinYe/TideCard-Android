# 潮汐改卡 USB 工具 1.1.4

当华为 / 鸿蒙手机能在资源管理器打开存储、电脑工具却找不到设备时，新版可区分文件传输、HDB / HDC、ADB 驱动异常、待授权和离线，提供对应排查入口。

- 新增“连接诊断 / 华为”：只读查询 Windows 当前华为 USB 接口及 ADB 状态，提供华为官方驱动入口、设备管理器和复制脱敏诊断。
- 隔离可能影响连接的 ADB 继承环境，固定本机标准端口，为新启动的服务指定 Windows 原生 USB 后端；全局环境及已运行服务不变。
- 保留高 DPI 布局、覆盖安装和版本保护；随附原签名 **Android 2.4.1** APK。

## 下载与使用

下载 **TideCard-USB-1.1.4-Windows.zip**，完整解压后运行 `TideCard-USB.exe`。需要 Windows 10 / 11、.NET Framework 4.8；手机需手动开启 USB 调试并允许自己的电脑。

华为设备识别不到时，点“连接诊断 / 华为”。若需安装驱动，通过官方手机助手选择“**HarmonyOS 4 及以下**”，再使用“安装 USB 驱动”入口。HDB 授权不能代替 ADB 的 RSA 授权；HarmonyOS 4.2 不应直接套用 HarmonyOS 5 的 HDC 流程。详细检索依据与步骤见 [华为连接诊断](https://github.com/DustinYe/TideCard-Android/blob/usb-v1.1.4/docs/HUAWEI_USB.md)。

这是独立的电脑工具发布，Android 最新版本仍为 **2.4.1**。手机版本更高时停止安装，不强制降级。驱动缺失仍需在受影响电脑上处理。

## 验证范围

通过 52 项诊断断言、43 项原有模拟流程断言，以及主窗口 / 诊断窗口共 28 组 DPI 与窄窗口布局检查。实际 Windows 接口查询和随附 ADB 启动正常，本机没有连接手机。

**受影响华为手机不在现场，尚未验证该机的 USB 连接、后台激活、SIM 写入或恢复。** 新版提供诊断和客户端兼容调整，不代表已经确认该机根因或修复所有鸿蒙 4.2 设备。

Windows EXE 暂无 Authenticode 签名。ZIP 内提供逐文件校验，外部 `SHA256SUMS.txt` 提供工具包与源码包的 SHA-256。
