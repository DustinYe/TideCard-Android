# 潮汐改卡 USB 工具 1.1.10

随附 APK 更新为同签名 **Android 2.4.3 / 版本码 14**，新增手机端旧地区配置检查与确认清除。USB 激活协议、诊断和电脑更新流程保持不变；电脑工具不会自动清除或更改手机地区。

完整解压后运行 `TideCard-USB.exe`，安装并激活后，在手机主界面或“设置 → 旧地区配置”操作。清除范围与限制见 [Android 2.4.3 说明](https://github.com/DustinYe/TideCard-Android/releases/tag/v2.4.3)。

Windows EXE 仍无 Authenticode 签名，可能显示 SmartScreen 提示。受影响 OPPO 和朋友电脑未在现场验证；主机模拟与构建通过不代表该机清除成功。
