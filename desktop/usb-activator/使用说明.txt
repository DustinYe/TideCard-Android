潮汐改卡 · Windows USB 激活工具 1.1.6（配套 APK：2.4.1 正式版）

本次更新
修复只查询华为 USB 节点造成 OPPO 等品牌漏检的问题，改为通用 USB / ADB / MTP 候选检测。新增“OPPO / 厂商帮助”，区分客户端、设备查询、RSA 授权、安装和连接后的 shell 拒绝。客户端正常但设备查询失败时，增加本机 127.0.0.1:5037 只读 ADB 协议检查。保留客户端错误码、文件存在检查、原签名 2.4.1 APK 与数据保护。受影响 OPPO / ColorOS 实机效果仍需用户验证。

用途
当手机无线调试不显示配对码 / IP，或不方便无线配对时，通过电脑 USB 启动潮汐改卡内置后台。无需 Android Studio，无需安装外部 Shizuku，无需输入配对码。

使用步骤
1. 将 ZIP 完整解压到电脑文件夹，不要直接在压缩包里运行。
2. 手机开启开发者选项和 USB 调试，用可传输数据的数据线连接这台电脑。
3. 打开 TideCard-USB.exe，手机弹出“允许 USB 调试”时，确认是自己的电脑后点允许，再点击“刷新设备”。
4. 选择目标手机，点击“安装 / 更新并激活”。工具会安装配套 APK，保留应用数据。如手机提示 USB 安装，请手动允许。
5. 电脑与手机均显示后台已激活后，可以拔线。手机点“返回改卡界面”，自行选择地区与卡槽并开始。

要求与限制
- Windows 10 / 11，.NET Framework 4.8；常见 Windows 安装已包含该运行时。工具无需管理员权限。
- Android 11 或以上，目前仅支持主用户（用户 0），不支持系统分身、访客或工作空间。
- 手机必须手动开启 USB 调试并允许电脑。不能通过导入普通文件替代系统授权。
- 无需开启无线调试。电脑激活不会自动选择地区或开始改卡。
- 激活成功后可拔线；重启或后台被系统终止后可能需要重新激活。
- 后台激活与 CarrierConfig 改卡权限是两件事。该工具解决激活入口，不保证所有 OPPO / 华为 / vivo / HyperOS 机型允许改卡。
- 当前正式版包含 HyperOS shell 限制兼容尝试；vivo 与报错的 Redmi K80 Ultra 仍需各自实机验证，机型兼容范围见仓库验证记录。

已有应用
- 每次激活都会覆盖安装随附 APK（adb install -r），保留数据。无需卸载旧应用。
- 原应用签名不一致时停止，不会卸载原应用或清除数据；手机版本更高时停止，不会强制降级。
- 更换、清除或卸载潮汐改卡前，请在原应用中停止改卡并恢复。

常见问题
- 诊断显示“ADB 未正常返回设备列表”：先查看“ADB 客户端自检”和“ADB 设备查询”的分类 / 错误码；应用界面能打开不能证明随附 ADB 能运行。若文件缺失，重新完整解压，保留 EXE 旁的 adb 子文件夹及其中两个 DLL。
- 设备列表为空：点“连接诊断”查看接口与驱动状态；能打开手机存储不代表 ADB 已连接。确认 USB 调试、数据线、USB 接口与连接模式；必要时安装手机厂商官方 USB 驱动。
- 显示待授权：解锁手机，允许 USB 调试。没有弹窗时重新插线，或撤销旧 USB 调试授权后重新连接。
- 安装被拒绝：检查手机上的 USB 安装提示，以及开发者选项中的 USB 安装设置。
- 后台连接超时：不代表成功。保持手机解锁，检查应用界面，再重新激活；若仍失败，需要该机型的实际诊断。

OPPO / ColorOS 与通用连接排查
1. 保持手机解锁，开启 USB 调试，选择“传输文件”。请通过 USB 调试 RSA 弹窗确认自己的电脑。
2. 点“连接诊断”，先看客户端自检与设备查询；当前候选接口检测不限定华为，品牌名称和 VID 仅作线索，不代表机型 / ROM 已确认。
3. 若客户端正常、设备查询超时，先拔下手机再诊断。若仍超时，可关闭使用 ADB 的手机助手、模拟器、Android Studio 等程序，在任务管理器结束 adb.exe 再重开工具；其它 ADB 连接会断开。若 5037 返回非 ADB 协议，需先核对端口占用程序。
4. 如果客户端和列表正常但没有手机，按数据线、USB 模式、RSA 授权与目标 ADB 接口依次排查。OPPO 用户从“OPPO / 厂商帮助”进入 OPPO 官方连接说明；华为专用 HiSuite 单独列出。
5. ColorOS 的权限监控说明用于“已连接后 shell 命令被明确拒绝”的阶段；不能用来解释所有设备查询超时。具体选项名称需按实际 ROM 核对。
6. 反馈时复制完整新版脱敏诊断，确认顶部显示 1.1.6，并提供 OPPO 型号、ColorOS / Android 版本。旧版“华为接口数=0”不能用于判断 OPPO 是否枚举。
OPPO 官方：https://support.oppo.com/ph/answer/?aid=neu10634
Android OEM 驱动：https://developer.android.com/studio/run/oem-usb
ColorOS 权限说明：https://shizuku.rikka.app/zh-hans/guide/setup/
华为专用：https://consumer.huawei.com/cn/support/hisuite/

安全与来源
激活和诊断使用本地随附 ADB / Windows 接口查询；设备查询失败时仅对本机 ADB 端口做有超时的只读协议检查，不上传设备信息。官网按钮由用户点击后通过浏览器打开。仅操作用户所选的手机。电脑日志不包含安装激活令牌；电脑仅在内存处理激活信息，不保存到日志或文件。令牌按既有设计保存在手机应用私有存储。
工具不卸载应用、不清除数据、不执行恢复出厂设置，不开启网络 ADB 端口，不重启手机，不通过停止或杀死其他调试程序来激活。
配套 APK 沿用潮汐改卡原签名。Windows EXE 尚无代码签名；SHA256SUMS.txt 提供各文件校验值。
TideCard 源码与许可：https://github.com/DustinYe/TideCard-Android （Apache-2.0，随附 LICENSE.txt）。
ADB 为未修改的 Android SDK Platform-Tools 37.0.1 官方组件；来源：https://developer.android.com/tools/releases/platform-tools 。完整组件声明见 adb/NOTICE.txt，版本见 adb/source.properties。
ADB 官方使用说明：https://developer.android.com/tools/adb
应用内第三方组件及许可保留于 APK 的 assets；可在应用“使用说明 → 开源许可”查看。
